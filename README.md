## 📋 Описание

**CSV.Convertor** — это десктопное приложение для Windows, которое конвертирует CSV-файлы в формат XLSX (Excel) с автоматическим определением:

- Кодировки (UTF-8, Windows-1251 и другие)
- Разделителя (`,`, `;`, `TAB`, `|`)
- Типов данных (числа, даты, строки, булевы)

Созданные Excel-файлы содержат:
- ✅ Жирные заголовки с серым фоном
- ✅ Автофильтр для всех колонок
- ✅ Закреплённую первую строку и первый столбец
- ✅ Правильное форматирование чисел и дат
- ✅ Активную ячейку в `B2` при открытии

---

## 🚀 Возможности

| Функция | Описание |
|---------|----------|
| **Автоопределение** | Кодировка и разделитель определяются автоматически |
| **Ручной выбор** | Можно вручную задать разделитель (`,` `;` `TAB` `\|`) |
| **Преобразование типов** | Поддержка `string`, `int`, `double`, `DateTime`, `bool` |
| **Форматирование** | Цены с 2 знаками, Units с умными десятичными |
| **Закрепление** | Первая строка и первый столбец всегда видны |
| **Автофильтр** | Фильтры для всех колонок |
| **Прогресс-бар** | Визуальный индикатор выполнения |
| **Сохранение** | Файлы сохраняются в папку `Документы\CSV.Convertor\output` |
| **Повторная конвертация** | Диалог "Конвертировать ещё?" после завершения |

## 📥 Установка

### Вариант 1: Установщик (рекомендуется)

1. Перейдите в раздел [Releases](https://github.com/LucasVakhos/CSV.Convertor/releases)
2. Скачайте `CSV.Convertor.Setup.exe`
3. Запустите установщик — приложение установится в `Program Files`, создастся ярлык на рабочем столе и в меню «Пуск»
4. **.NET Runtime не требуется** — приложение собрано как автономный single-file exe

### Вариант 2: Portable-версия

1. Скачайте `CSV.Convertor.exe` из релизов
2. Запустите файл — установка не требуется

### Вариант 3: Собрать из исходников

```bash
# Клонируем репозиторий
git clone https://github.com/LucasVakhos/CSV.Convertor.git

# Переходим в папку проекта
cd CSV.Convertor

# Восстанавливаем зависимости
dotnet restore

# Собираем проект
dotnet build -c Release

# Запускаем (опционально)
dotnet run
